Product overview

A banking-grade wallet with no bank in the middle.

OpenExpense is a static GitHub Pages app. The browser is the runtime. There is no application server, no user account, and no first-party ledger upload. Autosave encrypts the calendar in IndexedDB. Export writes an encrypted ledger.json and a sibling key.json that you keep.

Who it is for

Households, contractors, and host apps

  • People who want a calendar wallet without creating an account
  • Anyone who must keep a portable encrypted backup they control
  • Banks and tools that already fetch transactions and need a private UI/engine

Features catalog

Capabilities that stay on-device.

Calendar wallet

Month grid with net-up / net-down badges. Drag a chip to another day to move it.

Snapshot slides

Overview, Income, and Expenses. Unpaid bills stay separate from still-expected paychecks.

Recurring series

Weekly, monthly, bimonthly, or quarterly. Edit or delete one weekday or the whole series.

Encrypted autosave

AES-256-GCM in IndexedDB. The device key is non-extractable and is not key.json.

Portable export

Encrypted ledger.json plus a sibling key.json. Linked-folder Save stages a recovery pair first.

On-device OCR

Receipt photos and PDFs are parsed in the page. Images are not uploaded.

Monthly PDF

A brochure spending or income report is generated locally with the same navy tokens.

Host engine

engine.js and window.OpenExpense let a banking app set and get calendar data. No Plaid calls here.

User instructions

From first open to a key you can hold.

1

Open a secure context

Use https://www.openexpense.org or localhost. Do not open the HTML as file://. Encryption needs a secure context.

2

Name the ledger

Autosave is on by default. The disk icon writes an encrypted record to this browser only.

3

Tap a day and add a line

Save an expense or income. Mark paid or received. Recurring copies land on the cadence you choose.

4

Scan if you want a draft

Camera or file. OCR and PDF text run locally. Confirm the merchant and amount before save.

5

Read the snapshot slides

Overview is settled cash and bills. Income shows still-expected checks. Expenses shows unpaid bills.

6

Export both files

Keep ledger.json and key.json together, or apart on purpose. Anyone with both can decrypt that export.

Standard operating path

Import later with the matching key.json. A plaintext JSON import is allowed only after you confirm, then it is stored encrypted.

System specs

  • Version 2.2.0 · MIT License
  • AES-256-GCM · 96-bit IVs
  • IndexedDB ledger + meta key
  • Static GitHub Pages host
  • Secure context required
  • engine.js ~13 KB headless API

Privacy

No accounts. No analytics collector. Receipt pixels stay in-page. The portable key is not written to IndexedDB or localStorage. A browser-profile attacker remains out of scope, as stated in SECURITY.md.
