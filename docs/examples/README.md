# Examples

[`sample-ledger.json`](sample-ledger.json) is a **fictional** household ledger you can import to see the calendar, recurring groups, and monthly summary.

It is not loaded by the app. To try it:

1. Open OpenExpense on `localhost` or the public site.
2. Use **Import** and choose this file.
3. Autosave will encrypt a copy into this browser’s IndexedDB.

Do not replace this file with a real export. Real ledgers and `ledger.key.json` files stay off git.
